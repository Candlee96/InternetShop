# Архитектура прототипа

`Models` содержит предметные сущности: пользователей, товары, позиции корзины и заказы.

`Services` содержит склад, сервис создания заказа и реализации паттернов проектирования.

`ShoppingCart` отвечает за состав корзины, а `OrderService` переводит ее в заказ и списывает товар со склада. `Order` хранит стратегию состояния через `IOrderState`, а способ оплаты передается в `OrderService` через `IPaymentStrategy`.

Такое разделение соответствует UML: сущности не зависят от консольного интерфейса, а сценарий в `Program.cs` показывает сборку компонентов в работающий прототип.
